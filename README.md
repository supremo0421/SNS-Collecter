# SNS 게시물 수집기

X(구 트위터)의 특정 계정에서 날짜 조건에 맞는 게시물을 찾아 사진 원본, 게시물 본문, 공개 정보를 로컬 폴더에 정리해 주는 윈도우용 프로그램입니다.

계정 비밀번호를 프로그램에 입력하지 않습니다. 프로그램 전용 크롬 창에서 사용자가 직접 로그인하며, 로그인 정보는 컴퓨터의 전용 크롬 프로필에만 보관됩니다.

## 주요 기능

- 수집할 X 계정을 자유롭게 추가·수정·삭제
- 여러 계정을 한 번에 수집
- 한국 시간을 기준으로 게시물 날짜 판정
- 원본 사진과 게시물 본문 저장
- 게시물 주소, 작성 시각, 첨부 정보를 정보 파일로 저장
- 리트윗, 인용된 다른 게시물의 미디어, 외부 링크 미리보기 이미지 제외
- 본문 검색어 지정과 답글 포함 여부 선택
- 일시정지, 이어서 수집, 실패 항목 재시도
- 이미 정상적으로 저장된 항목 자동 건너뛰기
- 수집 결과와 오류를 작업 기록 파일로 저장

## 수집 방식

### N년 전 오늘

기준 날짜의 월·일과 같은 과거 날짜를 연도별로 검색합니다. 예를 들어 기준 날짜가 2026년 9월 5일이고 과거 연도를 2022년부터 2025년까지 지정하면, 각 계정의 2022년·2023년·2024년·2025년 9월 5일 게시물을 수집합니다.

### 기간 지정

시작 날짜와 종료 날짜를 직접 입력해 해당 기간의 사진 게시물을 수집합니다.

### 한 달 메타데이터

선택한 달에 올라온 게시물 중 **사진 또는 영상이 직접 첨부된 게시물만** 찾습니다. 사진과 영상 파일은 내려받지 않고 다음 내용만 저장합니다.

- 게시물 본문과 주소
- 작성 시각
- 첨부 미디어 종류
- 공개된 사진 주소와 크기 정보
- 영상 미리보기 주소와 확인 가능한 공개 정보

텍스트만 있는 게시물, 리트윗, 외부 사이트의 미리보기 이미지는 제외됩니다. 현재 달을 선택하면 오늘까지 수집합니다.

## 실행 준비

- 윈도우 10 또는 윈도우 11
- 구글 크롬
- X 계정
- 인터넷 연결

배포 폴더의 _internal 폴더와 실행 파일을 항상 함께 보관해야 합니다.

## 처음 실행하는 방법

1. 배포 ZIP 파일 전체의 압축을 풉니다.
2. SNS-Collector-v04.exe를 실행합니다.
3. **Chrome 세션 확인**을 누릅니다.
4. 프로그램 전용 크롬 창이 열리면 X에 직접 로그인합니다.
5. 로그인 완료 상태가 확인되면 수집 조건을 설정합니다.
6. 저장 폴더를 지정합니다.
7. **미리보기**로 대상 게시물을 확인하거나 **수집 시작**을 누릅니다.

프로그램 전용 크롬의 로그인 상태는 다음 실행에도 유지됩니다. 일반 크롬의 로그인 상태와는 별개입니다.

## 계정 설정

1. **대상 계정** 입력란에 아이디 또는 계정 주소를 입력합니다.
2. **추가**를 누릅니다.
3. 등록된 계정의 연필 단추를 누르면 아이디를 수정할 수 있습니다.
4. × 단추를 누르면 계정을 삭제할 수 있습니다.

아이디, @아이디, X 계정 전체 주소 형식을 모두 사용할 수 있습니다.

## 게시물 수집 방법

1. **수집 방식**을 선택합니다.
2. 날짜 또는 수집할 달을 지정합니다.
3. 필요하면 본문에 포함할 검색어를 입력합니다.
4. 답글도 필요하면 **답글 포함**을 선택합니다.
5. 결과를 저장할 폴더를 지정합니다.
6. **미리보기**를 눌러 대상 게시물을 확인합니다.
7. **수집 시작**을 누릅니다.

수집 도중 일시정지하거나 중단해도 이미 저장된 파일은 유지됩니다. 다시 실행하면 정상 저장된 항목을 검사한 뒤 건너뜁니다.

## 저장 구조

### 사진 수집

저장 폴더 → 계정 → 날짜 → 게시물 번호 아래에 이미지 원본, 본문.txt, 정보.json이 저장됩니다.

사진은 X가 제공하는 원본 크기 주소로 내려받고, 공개된 원본 크기 정보와 실제 파일 해상도를 확인합니다.

### 한 달 메타데이터

저장 폴더 → _메타데이터 → 계정 → 날짜 → 게시물 번호 아래에 본문.txt와 정보.json이 저장됩니다.

메타데이터는 별도 폴더에 저장되므로 기존 사진 보관 폴더의 파일과 검증 정보를 덮어쓰지 않습니다.

### 수집 기록

저장 폴더 → _수집기록 아래에 작업 시각 이름의 JSON 파일이 저장됩니다. 최종 수집기록은 작업 종료 시 한 번만 안전하게 교체 저장됩니다.

## 오류가 발생했을 때

### 로그인이 필요하다고 표시되는 경우

**Chrome 세션 확인**을 누른 뒤 프로그램 전용 크롬 창에서 로그인 상태를 확인합니다.

### 로그인이 일시적으로 제한된 경우

로그인 시도를 반복하지 말고 잠시 기다린 뒤 다시 확인합니다. 프로그램에서 X의 로그인 제한을 해제할 수는 없습니다.

### 검색 결과가 일부만 수집된 경우

X 검색 결과 노출 방식이나 요청 제한 때문에 일부 게시물이 검색되지 않을 수 있습니다. 프로그램은 이런 상황을 0건 성공으로 처리하지 않고 일부 완료 또는 오류로 표시합니다. 잠시 기다린 뒤 **재시도**를 사용합니다.

### 프로그램을 중단한 경우

이미 저장된 사진과 게시물 정보는 남아 있습니다. 같은 조건으로 다시 실행하면 완료된 항목을 확인하고 이어서 수집합니다.

## 개인정보와 로그인 정보

- X 아이디와 비밀번호는 프로그램이 수집하거나 별도 파일로 저장하지 않습니다.
- 로그인은 프로그램 전용 크롬 창에서 사용자가 직접 진행합니다.
- 로그인 쿠키와 세션은 사용자 컴퓨터의 전용 크롬 프로필에 저장됩니다.
- 수집 결과는 사용자가 지정한 로컬 폴더에만 저장됩니다.

## 유의 사항

- X 검색 결과에 노출되지 않는 게시물은 수집되지 않을 수 있습니다.
- 계정이 비공개이거나 게시물이 삭제·차단된 경우 내용을 가져올 수 없습니다.
- 짧은 시간에 많은 요청을 보내면 X에서 요청을 제한할 수 있습니다.
- 수집한 자료의 이용과 보관은 X 이용약관과 저작권을 확인한 뒤 진행해야 합니다.
